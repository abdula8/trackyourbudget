BUDGET CALCULATOR APPLICATION
Version 1.0.0

OVERVIEW
========
Budget Calculator is a powerful desktop application designed to help you manage your monthly budget and track expenses efficiently. The application features an intuitive interface for adding, editing, and categorizing expenses, with automatic category detection and comprehensive reporting capabilities.

FEATURES
========
- Easy expense entry with automatic category detection
- Custom category management with keyword support
- Monthly budget tracking with visual progress indicators
- Advanced filtering and search capabilities
- Data export to Excel format
- Expense analysis and reporting
- Multi-language support (English and Arabic)
- Optimized performance with SQLite database

INSTALLATION
============
1. Run the BudgetCalculatorSetup.exe installer
2. Follow the on-screen instructions
3. Choose your preferred installation options:
   - Desktop shortcut (recommended)
   - Start Menu shortcuts
   - AnyDesk remote desktop software

SYSTEM REQUIREMENTS
===================
- Windows 7 or later
- 50 MB free disk space
- Internet connection (for AnyDesk installation)

USAGE
=====
1. Launch Budget Calculator from your desktop or Start Menu
2. Set your monthly budget using the budget input field
3. Add expenses by entering description, amount, and date
4. Use the "Auto" category option for automatic categorization
5. Create custom categories using the "Manage Categories" button
6. Filter and search your expenses using the filter controls
7. Export your data to Excel for further analysis

CUSTOM CATEGORIES
================
You can create custom expense categories with specific keywords:
1. Click "Manage Categories" button
2. Enter category name and keywords (comma-separated)
3. Click "Add Category"
4. The system will automatically detect these categories in future expenses

UNINSTALLATION
==============
To uninstall Budget Calculator:
1. Go to Control Panel > Programs and Features
2. Find "Budget Calculator" in the list
3. Click "Uninstall" and follow the prompts

Alternatively, use the Uninstall shortcut in the Start Menu.
